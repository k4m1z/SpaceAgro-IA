# SpaceAgro AI

## Descrição
Sistema inteligente de monitoramento agrícola utilizando dados espaciais, sensores ESP32 e Inteligência Artificial.

## Objetivo
Auxiliar agricultores na identificação precoce de riscos climáticos e períodos de seca.

## Tecnologias Utilizadas
- Python
- Pandas
- Matplotlib
- Scikit-Learn
- ESP32
- Inteligência Artificial

## Integrante
Camila Duarte Ferreira

## Funcionalidades
- Monitoramento climático
- Coleta de dados ambientais
- Previsão de risco de seca
- Dashboard para visualização de dados
